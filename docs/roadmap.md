# Integrated delivery roadmap

All ten modules are in scope from the beginning. Implementation is staged around dependencies and can be parallelised after contracts are agreed.

1. Foundation: monorepo, API, database, auth boundary, CI and design system.
2. Market data + terminal: one real provider end-to-end, charting and feed-health states.
3. ICT + multi-timeframe: deterministic detections, rule versioning and replay tests.
4. AI + setup + risk: grounded analysis, deterministic prices and setup lifecycle.
5. Alerts + watchlists + journal + backtesting: event-driven integration and shared strategy rules.
6. Mobile + production hardening: mobile client, security, observability, load and recovery tests.

Release gates are based on tested functionality, not screen completion.
